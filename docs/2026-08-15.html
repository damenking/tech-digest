OpenAI previews Ultrafast mode: GPT-5.6 Sol at up to 14x speed via Cerebras
OpenAI announced a new API service tier called Ultrafast, which runs GPT-5.6 Sol at up to 750 output tokens per second — roughly 14 times faster than standard inference. The performance gains come from a partnership with Cerebras, the chip company that has built wafer-scale AI inference hardware specifically designed to minimize the memory bandwidth bottleneck that makes standard GPU inference slow for sequential token generation. This is a meaningful number: at 750 tokens per second, you're looking at generating a full page of text in under a second, which opens up use cases that were previously impractical due to latency. The catch is that this is GPT-5.6 Sol, which is OpenAI's more efficient 'small' model rather than the full frontier model — so you're trading some capability for a lot of speed. For agentic workflows where you need rapid back-and-forth reasoning steps, this tradeoff often makes sense. The Cerebras partnership is interesting because it signals OpenAI is willing to use third-party silicon for inference, not just Nvidia GPUs, at least for specific tiers. This also puts pressure on competitors to match inference speed, not just benchmark scores. Developers building real-time applications like coding assistants or interactive agents should pay attention to this tier.

This is a genuinely hard engineering problem: HE has long been theoretically elegant but practically unusable due to the enormous computational overhead it imposes.

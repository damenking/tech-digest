Eight eMudhra Intermediate CA Certificates Compromised, Internet on High Alert
This is as serious as it gets for web security: the private keys for eight intermediate certificate authority certificates issued by Indian CA eMudhra have been compromised. Because these certificates chain up to roots trusted by Mozilla, Microsoft, Apple, and Chrome — which together cover essentially the entire internet — an attacker holding these keys can mint valid TLS certificates for any website on the planet, with no way for a browser to know they're fake. That's the nightmare scenario for PKI (public key infrastructure). Eight intermediate CAs is not a small incident; each one can sign for arbitrary domains, meaning the blast radius is theoretically unlimited. The immediate mitigation requires every piece of software that bundles a trusted certificate list to push an emergency update — browsers, operating systems, libraries, embedded devices, you name it. A dedicated tracking site (emudhra.we-have-a-problem.com) has been stood up to monitor which software has patched. The story was trending at the top of Hacker News with nearly 1,000 points, reflecting how seriously the security community is taking this. For context, intermediate CA compromises of this scale are extraordinarily rare — the last comparable event was the DigiNotar collapse in 2011, which ultimately destroyed that CA. Enterprises running internal certificate pinning or custom trust stores need to audit their exposure immediately. If you operate infrastructure that does TLS certificate validation anywhere in the chain, this needs to go on your radar today, not next week.
